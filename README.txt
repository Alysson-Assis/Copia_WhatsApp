WhatsApp UI clone — React Native (front-end only)

Como usar:
1. Abra um projeto React Native/Expo.
2. Substitua o conteúdo do App.js por este arquivo.
3. Rode o projeto normalmente (por exemplo: npx expo start).

Não há backend, autenticação nem envio real de mensagens. A pesquisa e os filtros
Todas, Não lidas e Grupos funcionam com os dados fictícios. A aba Favoritos,
os botões e as conversas são demonstrações visuais.
